Ollama: Local LLM Integration with Python

This repository demonstrates how to run a Large Language Model locally using Ollama and integrate it with Python through Jupyter Notebook.

The implementation uses Meta's Llama 3.2 3B model and covers two key functionalities:

Local LLM Integration: Connecting Ollama with Python to generate responses without relying on cloud-based APIs.

Continuous Chat: Implementing conversational AI with conversation history, allowing the model to retain context across multiple interactions.
